# ADR-0014: Canonical Concept Network Projection & API Gateway Envelopes

- **Status:** ACCEPTED
- **Date:** 2026-09-02
- **Context:** Discovery Engine - Phase 5.4 & Phase 6.1

## Context
Keşif motoru çıktılarını görselleştirmek ve dış dünyadaki istemcilere (Web/Mobile) sunmak için domain katmanını UI kütüphanelerinden (Cytoscape, D3, Vis.js) tamamen bağımsız tutacak bir mimari ve standart HTTP yanıt zarfı gerekmektedir.

## Decisions
1. **Canonical Network Representation:** `ConceptNetworkDTO` yapısı UI kütüphanelerinden bağımsız olarak düğüm (`nodes`) ve yönlü kenar (`edges`) modelini temsil eder.
2. **Adapter Pattern for Visualization:** `ConceptGraphAdapter` domain verisini canonical modele çevirir; `CytoscapeProjectionAdapter` ise bu veriyi Cytoscape.js formatına dönüştürür.
3. **Standardized API Envelope:** `DiscoveryGatewayController` üzerindeki tüm yanıtlar tip güvenli `APIResponse<T>` zarfı (`success`, `data`, `error`, `timestamp`) ile kapsüllenir.

## Consequences
- Domain katmanı frontend/görselleştirme kütüphane değişikliklerinden etkilenmez.
- Tüm API istemcileri standart hata ve veri zarfları alarak öngörülebilir entegrasyon sağlar.# ADR-0014: Interactive Concept Network Projection Layer

## 📋 EXECUTIVE SUMMARY

ADR-0014, Discovery Engine (Phase 5.3) tarafından üretilen `DiscoveryResultDTO` verisini, UI üzerinde görselleştirilebilir bir formata dönüştüren ara katman (Projection Layer) mimarisini tanımlar.

**Core Decision:** Canonical `ConceptNetworkDTO` modeli aracılığıyla Discovery Engine'i tüm visualization kütüphanelerinden (Cytoscape, D3, Vis.js, Sigma.js) izole etmek ve API Gateway seviyesinde geriye dönük uyumluluğu schema versiyonlama, güvenlik tavanı (graph ceiling) ve yönlülük bayrakları ile garantiye almak.
