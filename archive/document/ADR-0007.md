# ADR-0007 — TranslationRepository Contract

* **Tarih:** 2026-08-31
* **Durum:** Kabul Edildi (Accepted)
* **Faz:** Faz 2 (Translation Platform)
* **Etkilenen Katmanlar:** Repository, Service

---

## Bağlam ve Problem Tanımı

Sözlük verilerine erişim, kayıtların saklanması ve sorgulanması için servis katmanından bağımsız, katı sınırları tanımlanmış bir veritabanı/depo arayüzüne (`contract`) ihtiyaç duyulmaktadır. Depo (Repository) katmanının mantıksal işlemlerle (matching, diyalekt dönüşümleri, anlamsal gruplama) kirletilmesi mimari bağımlılıkları karmaşıklaştırmaktadır.

---

## Mimari Veri Akışı

Sistemdeki veri akış sırası aşağıdaki gibidir:

`Source` → `Loader` → `Normalizer` → `Repository` → `Service` → `Hook` → `UI`

---

## Karar

1. **Katman Bağımsızlığı:** `TranslationRepository` üst katmanları (`Service`, `UI`, `Hook` vb.) kesinlikle içe aktaramaz (`import` edemez).
2. **Sorumluluk Ayrımı:**
   * **Repository:** Yalnızca veriyi saklar, getirir, doğrudan lookup sağlar, indeks sorgusunu çalıştırır ve deterministik veri döner.
   * **Service:** `TranslationGroup` sentezleme, Word Family işleme, diyalekt dönüştürme ve `CrossDictionaryMatching` karar mekanizmalarını yürütür.

---

## Repository Boundary Rules

### Repository Katmanı Şunları Yapabilir (MAY):
- Deterministik ID üzerinden kayıt getirmek.
- Birebir dil ve lemma eşleşmesine göre kayıt getirmek.
- Hedef anlam metni içerisinde doğrudan alt dize (substring / contains) araması yapmak.
- Ham `TranslationEntry` dizilerini toplu kaydetmek (`saveBatch`).

### Repository Katmanı Şunları Kesinlikle Yapamaz (MAY NOT):
- `TranslationGroup` nesneleri türetmek veya anlamsal gruplama mantığı çalıştırmak.
- Diyalekt dönüşüm kurallarını (`circassian_dialect_rules.json`) çalıştırmak.
- Semantik çıkarım, bulanık (fuzzy) eşleştirme veya fonolojik analiz yapmak.
- `CrossDictionaryMatching` kararı vermek.
- Diyalekt normalizasyonu veya kök ayıklaması yapmak.

---

## Search & Reverse Lookup Contract

`searchByMeaning()` ve `reverseLookup()` metotları için aşağıdaki arama kuralları geçerlidir:

* **Çalışma Prensibi:** Hedef dildeki anlam alanında verilen metnin doğrudan geçip geçmediğini (`contains / substring match`) kontrol eder.
* **Semantik Genişletme:** Yapılmaz.
* **Diyalekt Normalizasyonu:** Yapılmaz.
* **Çapraz Eşleştirme:** Yapılmaz.

---

## Minimum Interface Kontratı

```typescript
import { TranslationEntry } from "../domain/translation";

export interface TranslationQueryOptions {
  dialect?: string;
  limit?: number;
  offset?: number;
}

export interface ITranslationRepository {
  /**
   * Deterministik benzersiz kimlik ile tekil kayıt getirir (ADR-0004).
   */
  getById(id: string): Promise<TranslationEntry null |>;

  /**
   * Dil ve lemma bilgisine göre birebir kayıtları getirir.
   */
  getByLemma(language: string, lemma: string, options?: TranslationQueryOptions): Promise<TranslationEntry[]>;

  /**
   * Hedef dildeki anlam/açıklama metinlerinde doğrudan alt dize araması yapar.
   */
  searchByMeaning(targetLanguage: string, text: string, options?: TranslationQueryOptions): Promise<TranslationEntry[]>;

  /**
   * Hedef dilden kaynak dile tersine arama yürütür (Doğrudan metin eşleşmesi).
   */
  reverseLookup(targetLanguage: string, text: string, options?: TranslationQueryOptions): Promise<TranslationEntry[]>;

  /**
   * Toplu kayıt indeksleme ve kaydetme işlemi.
   */
  saveBatch(entries: TranslationEntry[]): Promise<void>;
}
