## 1. Context & Problem Statement
ADR-0009 ile dilden bağımsız `Concept` varlığının ULID kimliği, $M:N$ kardinalitesi ve Historical Merge kuralları dondurulmuştur. 

`ConceptRepository`, Phase 2 katmanına müdahale etmeden ve geriye dönük uyumluluğu (`116/116 PASS`) bozmadan kavram verilerini sunmak zorundadır. Bu ADR, `ConceptRepository` katmanının **Read-Model** kontratını, ULID çözümleme kurallarını ve $M:N$ polisemik sorgu davranışlarını belirler.

---

## 2. Invariants & Operational Rules

1. **Unidirectional Dependency Invariant:**
   $$\text{TranslationRepository} \not\to \text{ConceptRepository}$$
   `TranslationRepository` kesinlikle `ConceptRepository`'ye bağımlı olamaz. Phase 2 API'leri `ConceptRepository` kapalı veya erişilemez olsa dahi kesintisiz çalışır.

2. **ULID & Timestamp Invariant:**
   - Primary Key yalnızca **ULID** (`ConceptID`) olarak tanımlanır.
   - `createdAt` alanı sistem seviyesinde saklanan **domain timestamp** bilgisidir; ULID'den türetilen zaman (`ulidTimestamp`) salt-okunur metadattır.

3. **Alias Non-Primary Rule:**
   - `SemanticAlias` bir Primary Identifier değildir. `getConceptByAlias` sorguları **Canonical Alias Index** üzerinden en fazla bir aktif `Concept` çözer (0 veya 1).

4. **Deterministic Merge Chain Resolution:**
   - Birleşme zincirlerinde ($A \rightarrow B \rightarrow C$), `ConceptRepository` zinciri sonuna kadar takip eder ve nihai aktif kavramı (`Concept_C`) deterministik şekilde `supersededBy` referansı üzerinden çözerek döner.

5. **Empty Result Contract:**
   - Sorgularda eşleşen veri bulunmaması olağanüstü bir durum (exception) değildir. Liste sorguları boş koleksiyon (`[]`), tekil ULID sorguları ise `null` döner.

## 3. Query Contract (Read-Model Interfaces)

```typescript
// Pure Design Contract (Phase 3 Code Generation: FORBIDDEN)

type ConceptID = string; // ULID Standard
type MeaningID = string;
type EntryID = string;

enum ConceptLifecycleStatus {
  ACTIVE = "ACTIVE",
  DEPRECATED = "DEPRECATED",
  MERGED = "MERGED"
}

interface ConceptReadModel {
  readonly id: ConceptID;
  readonly semanticAlias?: string;
  readonly status: ConceptLifecycleStatus;
  readonly supersededBy?: ConceptID; // Final Resolved Target ULID
  readonly createdAt: number; // Domain Record Timestamp
}

interface ConceptMappingReadModel {
  readonly meaningId: MeaningID;
  readonly conceptId: ConceptID;
  readonly isPrimaryContext: boolean;
}

interface IConceptRepositoryReadModel {
  getConceptById(id: ConceptID): Promise<ConceptReadModel null |>;
  getConceptsByMeaningId(meaningId: MeaningID): Promise<ConceptReadModel[]>;
  getConceptsByEntryId(entryId: EntryID): Promise<ConceptMappingReadModel[]>;
  getConceptByAlias(alias: string): Promise<ConceptReadModel null |>;
}
