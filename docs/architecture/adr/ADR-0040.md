# ADR-0040: Morphological Root Taxonomy

## Durum
KABUL EDILDI

## Bağlam
Kumakhov (gl4.pdf) Kabardeyce'de kokleri siniflandirir.
Bu siniflandirma olmadan RootExtractor dogru calisamaz.

## Karar
Kokler aşağıdaki tiplere ayrilir:

| Tip | Tanim | Ornek |
|-----|-------|-------|
| Free Root | Tek basina gorunur | (serbest kokler) |
| Bound Root | Tek basina gorunmez | -сы, -лъы, -ты, -гъы, -къIэ |
| Neutral Root | Bağlama gore degisir | (notr kokler) |
| Stable Root | Kararli, degismez | (kararli kokler) |

## Oncelik
Root Type bilinmeden Prefix parse YANLIS sonuç verebilir.
Bu yuzden Root Taxonomy, Prefix Slot Grammar'dan ONCE gelir.

## Parser Sözleşmesi
RootClassifier girdi olarak yuzey formu alir,
cikti olarak RootType dondurur.
